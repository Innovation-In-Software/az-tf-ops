# Students

Lab 2 exercise. Add a file named after your GitHub username, on a branch, and
open a pull request.

```markdown
# Your Name

- Team: Summit Retail cloud operations
- Azure region I work in: eastus
- Something I want to stop doing by hand:
```

Then review a teammate's pull request before yours is merged. That is the whole
point of the exercise: the review, not the file.
